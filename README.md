# Multi-Vendor eCommerce Platform (Laravel 11)

A robust and scalable multi-vendor eCommerce platform built with **Laravel 11**, **MySQL**, and the **Repository Pattern**. This platform enables vendors to manage their products, users to shop seamlessly, and admins to control the entire ecosystem.

## 🚀 Features

### ✅ Completed

- **Multi-Authentication System**
  - Admin, Vendor, and User roles with custom dashboards

- **Multi-Vendor Feature**
  - Vendors can register and manage their stores/products

- **Advanced Product Variants**
  - Support for color, size, material, and more variants

- **Multi-Product Image Upload**
  - Upload multiple images for each product

- **Password Change Option**
  - Available for Admin, Vendor, and User roles

- **Advanced Product Coupon System**
  - Coupon management with multiple discount rules

- **Product Discount Feature**
  - Time-based and percentage-based discounts

- **Advanced Add-to-Cart**
  - Cart management with auto-update and quantity check

### 🔜 Upcoming Features

- **Advanced Product Search**
  - Filter by category, price, tags, vendor, ratings, etc.

- **Product Review & Rating System**
  - Users can leave reviews and rate products

- **Multiple Payment Gateways**
  - (e.g., PayPal, Stripe, Razorpay — pluggable system)

- **Product Wishlist**
  - Users can add products to their wishlist

- **Order Management**
  - Place, track, update, and manage orders

- **Shipping Rule System**
  - Zone-based or vendor-defined shipping rates

- **Blog Management System**
  - Admin-controlled blogging platform for SEO and engagement

- **Advanced Order Tracking**
  - Real-time tracking with status updates

- **Dynamic Newsletter Feature**
  - Manage subscriptions and send updates

- **Advertisement Feature**
  - Manage ads to monetize platform space

- **Transaction History**
  - View and manage payment and order logs

---

## 🛠️ Tech Stack

- **Backend:** Laravel 11
- **Database:** MySQL
- **Architecture:** Repository Pattern
- **Frontend:** Blade 
- **Payment:** Stripe, PayPal, etc.
- **Others:** Laravel Breeze for authentication
